附录 T　根本质疑与回应：C、A、T 真的独立吗

本附录正面处理对本书最根本的一个质疑。它不是技巧性的反驳，而是对框架前提的挑战："你把所有权衡都放进同一个三角，但这三个性质真的正交吗？"

最强批评的原话 "追求 C₂（计算完备）通常就意味着必须放弃 A₁（线性可组合）——这两者之间有一个因果强制，不只是一个成本权衡。你的三角隐含地假设了这三个性质是独立维度，但实际上它们在很多情况下是耦合的。"

T.1　三种可能的耦合，以及为什么它们不推翻三角

耦合 1：C 与 A 因果耦合 如批评所说，某些 C 与 A 可能被因果强制。
回应：本书从未假设 C 与 A 独立。恰恰相反，命题 2.2 的交互惩罚 ψ 就是用来刻画这种耦合的：当 ψ > 0 时，同时维持 C 与 A 比分别维持更贵——这正是因果耦合的成本形式。
结论：耦合不推翻三角，而是三角的一部分；ψ ≡ 0 时三角才不成立（推论 A.2.1）。
耦合 2：三者的坐标不是笛卡尔积 可达域 R(K) 可能不是 [0,1]³ 的子集而是其中一张曲面。
回应：第 2.9 节明确声明"本书不假设 R(K) 是凸三角形"；附录 A.6/A.10 的数值前沿正是弯曲的。三角是"三个正交轴上的投影坐标"，不是"可行域的形状"。投影坐标可以从非正交空间中取。
耦合 3：存在一个更根本的单一约束 也许有一个底层量（如"总描述复杂度"）同时决定 C、A、T，三角只是它的投影。
回应：这是最有价值的质疑，也是开放问题 O24（能否换一组坐标使取舍成为线性约束）。本书无法排除它。但即便存在，三角作为"投影坐标"仍有诊断价值——正如热力学量可以从统计力学投影出来，却仍是可用的工程坐标。我们把它登记为待攻问题，而不是假装已经回答。

T.2　独立性问题的一个可检验形式

独立性检验协议 要检验 C、A、T 是否独立，可执行：
（1）在多个领域测量三者的坐标 (c,a,t)；
（2）计算成对相关与偏相关（控制 K）；
（3）若某对性质在控制 K 后仍强相关，则它们不是独立维度，三角应降为二维或需要换坐标；
（4）若三者近似独立、且 (1,1,1) 不可达，则三角作为独立坐标是合理的。
状态：本书未执行该协议（缺少跨领域统一量表的坐标数据）；登记为研究议题（附录 L 的 O2/O10/O24）。

性质：条件分析，等级 C／丙。诚实结语：若最后一行为真，三角退化为"存在某种约束"——此时本书的诊断价值大部分消失，但形式化（第 2 章）、案例数据库（K）、诊断手册（G/H）仍可用。
本书的最终立场 我们不能证明 C、A、T 是独立的。我们能证明的是：在三个被独立研究过的复杂系统里，这三个性质以三种可区分的机制被让出（背景章、第 5/7/12 章）。
若这只是一枚硬币的三个面，那么本书的价值缩水为"提供了一个统一的叙述"；
若它们确实是三个独立但耦合的维度，那么本书提供了一个可操作的诊断坐标。
区分这两种情形，需要 U.2 的检验协议——这是留给读者的工作（O24）。
