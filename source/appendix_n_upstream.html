附录 N　计算、涌现与系统论：三角的上游

第 4 章只勾勒了三角与计算论、系统论、涌现的关系。本附录展开这三条"上游"线索。目的不是把三角塞进其中任何一个传统，而是说明：三角的取舍与这些传统所发现的边界共享同一个形状，但三角的严格性更低。

N.1　计算论：三种边界

计算论至少给出三种与三角相关的边界。

边界 1　可计算性（Turing） 停机问题表明：不存在一个算法，对任意程序与输入判定其是否终止。
三角读法：这是"完备性 C（对任意程序给出判定）"在整个图灵可计算范围内的不可达。它与三角的关系是警示性的：有些"完备"不是预算不够，而是逻辑上不可能。三角讨论的是预算约束，不是逻辑不可能——这个区别必须守住。
边界 2　计算不可约性（Wolfram） 对许多系统，不存在比直接模拟更快的预测方法。
三角读法：若系统计算不可约，则 C₃（预测完备）的实现需要与模拟等价的 K_comp。于是"提高 C₃"与"节省 K_comp 以实现传递 T"直接冲突。这是三角在 K_comp 受限情形下的一个硬实现。［论证，B／乙］
边界 3　P vs NP（Cook） 若 P ≠ NP，则不存在多项式时间的算法在最坏情形下求得 NP 困难问题的精确解。
三角读法："完备地刻画解空间（C）"与"在预算内找到可组合的解（A）"之间可能存在结构性鸿沟。子模最大化是 NP 困难的，而它恰恰是"能力组合"的抽象模型。这把 a 从"连续折扣"推向了"结构性不可达"。［论证，B／乙］
警告 N.1　不要把三角等同于这些定理 计算不可约性、停机问题、P vs NP 都是已证或强猜想的结果；三角是框架。宣称"三角 = 计算不可约性的推广"是过度宣称。正确的说法是：它们共享"有限预算/逻辑下的取舍"这一形状，三角借它们为自己的一个分量（K_comp）找到独立支持，但不声称等价。

N.2　算法信息论：描述预算的硬下界

Kolmogorov 复杂度 K(x) 定义为一个能输出 x 的最短程序的长度。它的核心性质（不可压缩性、不可计算性）直接对应三角的"K_desc 受限"。

不可压缩性与 C₁ 对长度为 n 的串，绝大多数满足 K(x) ≈ n（不可压缩）。
三角读法：若一个系统的描述预算 K_desc < n，则它不可能对多数对象给出"描述完备 C₁"的刻画——这是计数论证，不依赖任何假设。因此 C₁ 与 K_desc 之间存在一条硬下界。［定理，A／甲］

这条硬下界是三角中最严格的一部分：它说明"完备性"在描述预算受限时受计数约束，而不是受某个领域的特殊困难约束。第 5 章的子模性（信息论）与这里的不可压缩性（算法信息论）是同一条账的两个版本。

N.6　一个统一的问法

上游诸传统的共同问题 可计算性、计算不可约性、P vs NP、算法信息论、一般系统论、控制论、涌现理论，都可以被读成对同一个问题的不同回答：
"当描述能力、计算能力或制度资源有限时，系统能在多大程度上同时拥有完备、可组合与可传递？"
不同传统的差异，在于它们固定的"受限分量"不同：可计算性固定逻辑，计算不可约性固定 K_comp，算法信息论固定 K_desc，控制论固定干预能力，本书固定的是"多尺度 + 有限预算"的一般情形。这个统一问法本身就是本书对上游传统的一个贡献主张——但它是哲学层面的，等级 C／丙。

把这句话说清楚，也就说清楚了本书的定位：它不发明新的边界，而是给已有边界提供一张共同的坐标图。这张图可能画错，但它是可修改、可反驳、可替换的——这正是它相对于"又一个系统论"的差别所在。
