附录 R　演化视角的三角：生物、文化与技术

开放问题 O21 问："三角与生物演化的关系是什么？"本附录给出一个初步的、明确标为 C 级的回答。目的不是宣称"三角解释了演化"，而是检验：把"变异—遗传—选择"映到 C-A-T 后，能否复现演化生物学中已知的三类困境。

R.1　生物演化的三角映射

表 R.1　演化概念到 C-A-T 的映射
演化概念三角坐标含义
发育的保真（基因型→表型）C 完备性个体能完整、自洽地表达其遗传信息
性状的独立混合（自由组合）A 可组合性不同性状可加性组合，无强上位效应
适应性跨代传递T 传递性自然选择的累积可无损传到后代
性质：映射提案，等级 C／丙。注意：这是类比，不是同一；演化概念与三角坐标的对应依赖"用哪一层（基因/个体/种群）"。

R.2　演化生物学的三类困境

困境 1：高保真发育（C）导致重组时性状打乱（¬A） 若个体发育高度整合（C 强：性状间强耦合），则有性重组会打破有利的组合——这正是"性选择的代价"问题（Weismann、Maynard Smith）。
三角读法：选 C 的个体（高度整合的发育）在重组下损失 A（可加组合）。性繁殖之所以复杂，部分因为它在 C 与 A 之间制造持续张力。
困境 2：加法遗传假设（A）掩盖了非线性上位效应（¬C） 经典数量遗传学假设性状可加（A 强：可组合），但真实基因组充满上位效应（epistasis）与多效性（pleiotropy）——性状不能独立优化。
三角读法：要保住 A（可加、可预测的育种），就常要在 C（对基因互作的完整刻画）上付账。表观遗传学的兴起，正是对 ¬C 的一次修补。
困境 3：跨代传递（T）导致对当前环境的过度适配（¬A 或 ¬C） 强传递（T 强：适应性稳定传代）意味着更好的局部适配，但也意味着更差的换环境能力——生态脆弱性、专化陷阱。
三角读法：选 T（稳定遗传）常在 A（表型可塑性）或 C（对环境变化的响应完备性）上付账。"红皇后"式的军备竞赛，就是这个张力的动态表现。

R.3　文化演化与技术演化

表 R.2　三种演化系统的三角选择
系统传递机制（T）组合机制（A）保真机制（C）典型让出
生物演化基因复制重组/自由组合发育稳健性A（重组破坏组合）
文化演化模仿/教学观念混搭规范与制度C（模因的高保真低）
技术演化文档/专利模块化设计标准与测试T（跨代兼容难）
性质：对照表，等级 C／丙。来源：Boyd & Richerson（文化演化）、Dennett（模因）、Arthur（技术演化）。

三者的共同点。三种演化系统都表现出"复制 + 变异 + 选择"，也都在 C-A-T 上做取舍：生物演化让出 A（重组代价）、文化演化让出 C（模因保真低）、技术演化让出 T（兼容性差）。这支持一个弱结论：三角的取舍在演化系统中也出现（O21 的初步回答）。

警告 R.1　这个初步回答的强度很低 本附录是类比性映射C／丙，不是对 O21 的解决。要升级为 B 或 A，需要：（一）把"发育保真度""可加性""传递保真度"写成可测的量；（二）证明三类困境是同一约束的实例而非各自独立；（三）至少一个可反驳的定量预测。目前三项都缺。把本附录当作演化生物学的结论，是过度宣称。

R.4　一个可反驳的推论

推论 R.1（待检验） 若三角适用于演化系统，则"高度专化（T 或 C 强）的物种/技术，在面对环境突变时的崩溃概率，应高于泛化类型"，且这一差异应随环境变化幅度单调上升。
这是一个 L2 预测，可用古生物学（专化种的灭绝率）或技术史（专有技术的淘汰率）检验。若在高变化情形下专化类型并不更易崩溃，则本附录的映射被削弱。

登记。本推论已登记于附录 E（编号 P10），并列入研究议题库 O21。欢迎领域专家推进或证伪。

R.5　反面检验：演化映射会怎样被推翻

附录 R 的映射等级为 C／丙。与正文各章一致，这里写出会推翻它的具体证据。

反面检验 R.1（演化映射） □（映射失效）若"发育保真度""可加性""传递保真度"三者无法被写成可测的量，或三者的测量在控制种群规模后并不冲突——则映射只是修辞；
□（困境独立）若三类困境（重组代价、上位效应、专化脆弱）被证明各自有独立的机制解释，且不共享同一约束——则"三角适用于演化"为假；
□（推论被证伪）若在高环境变化下，专化类型并不比泛化类型更易崩溃（推论 R.1 被证伪）——则本附录的映射被削弱；
□（可塑性反例）若发现某个物种同时具有高发育保真（C）、高性状可加组合（A）与高跨代传递保真（T）——则 O7 在生物演化领域出现反例。
目前状态：未观察到上述任一项；映射仍为 C／丙。可操作性评级：中—难（需要比较生物学与古生物学的定量数据，属 5—10 年级研究）。
为什么这条映射值得登记（而非删除） O21 问"三角与生物演化的关系"。本附录给出的回答是"可能适用C／丙"，并附带一个可反驳推论 R.1。即便这条映射最终被证伪，它的价值也在于：它为三角提供了一个"是否只在人类知识系统内成立"的边界测试。若演化系统表现出与知识系统相同的取舍，三角的普适性提升；若不，则三角的适用范围收窄到"有描述/学习行为的系统"——这本身是有用的信息。
