附录 I　与已有不可能定理的对照

本附录把本书的三角与四个著名的"不可能/三难"结果逐条对照。目的不是宣称"它们是三角的特例"——那会降格它们；而是明确本书与它们的关系：结构相似，严格性更低，作用不同。

I.1　CAP 定理

表 I.1　CAP 与三角的逐项对照
项CAP本书三角
资源网络同步能力描述能力
三个坐标一致性 C / 可用性 A / 分区容忍 P完备 C / 组合 A / 传递 T
严格性已证（形式化）框架（部分见证可证）
作用分布式系统设计坐标跨领域诊断坐标
选择方式工程师显式选择 CP 或 AP往往隐性；诊断用于显式化

可借用的启示：工程师不会因 CAP 而放弃分布式系统，而是显式选择。本书希望知识系统也能如此。不可混淆之处：CAP 的 C/A 与本书的 C/A 缩写相同而含义不同，绝不可互换。

I.2　Arrow 不可能定理

表 I.2　Arrow 与三角
项Arrow本书三角
对象集体偏好排序多尺度知识系统的描述

严格性已证（公理前提下）框架

Arrow 与三角最深的相似在于：它们都说明"选择即失去"，而失去是可以被精确定位的。Arrow 告诉我们在公理层面失去哪个条件；三角告诉我们（在框架层面）失去哪一类账单。

I.5　差异总结

表 I.5　本书与已有定理的三点差异
差异已有定理本书三角

一句话：已有定理告诉我们"在选择点上必须失去什么"；本书试图告诉我们"如何在领域里找出那个选择点，并为失去的东西记账"。
