背景　从三个复杂系统到 C-A-T

本书的框架不是凭空构造的。它从作者此前三本书研究的三个复杂系统里"长"出来：记忆系统、区分（数学）结构、社会时间系统。这一页先精确描述这三个系统，再从它们共同的结构中引入并定义 C-A-T 框架。先有系统，后有坐标。

为什么从系统出发 如果把"不可能三角"直接当作公理抛出，它就只是一个口号。本书的做法相反：先给出三个被独立研究过的复杂系统，分别写出它们的变量、尺度与动力学，再看它们各自"卡"在哪里。三个卡点形状相同——这才是 C-A-T 的来源。［论证，B／乙］

背景.2　三个系统各自的"卡点"

系统一：记忆（《遗忘的边界》） 完备性 C：每个时间尺度（工作记忆、短期巩固、长期巩固、终身整合）都有一个精确的信息论描述——瓶颈、率失真、有效容量。
传递性 T：从毫秒级的突触动力学可逐级推导到终身记忆的形成（容量级联就是这条推导链）。
卡点：多个记忆系统的容量不能简单相加——子模性 I(Z;X₁∪X₂) ≤ I(Z;X₁)+I(Z;X₂)。
用坐标说：保住 C 与 T，让出 A。
系统二：区分结构（《区分的演化》） 完备性 C：有限图上的对象、分离、乘积都是代数完备的，可从有限数据精确计算。
可组合性 A：笛卡尔积图的谱等于因子谱之和（谱相加）；组合运算封闭且可加。
卡点：一旦走向光滑流形，加法结构失效——热核曲率 κ=R/6 与 Gauss–Bonnet 之间留下一个 1/3 的缺口，无法代数消去。
用坐标说：保住 C 与 A，让出 T。
系统三：社会时间（《错位的时间》） 可组合性 A：多种干预（财政、货币、监管）可组合、可比较。
传递性 T：长期效应可追踪，因果链可在多时间尺度上展开。
卡点：金融以秒计、政治以周计、生态以十年计；当 τ = T_min/T_available ≫ 1 时，置信区间发散，诊断退化为方向。
用坐标说：保住 A 与 T，让出 C。

背景.3　从这里定义 C-A-T

把三个卡点并排，得到三个被反复让出的性质。本书把它们命名为：

定义 0.1　C-A-T（速览，完整定义见第 2 章） 设系统 Σ = (E, R, ℒ, K)（元素、关系、尺度、复杂度预算）。
完备性 C：每个子系统 Σ_i 有自洽、可用、强到能预测的内部描述。三档：C₁ 描述完备 / C₂ 计算完备 / C₃ 预测完备。
可组合性 A：部分的组合不产生新的非线性项；能力可叠加。三档：A₁ 线性可组合 / A₂ 关系可组合 / A₃ 代数可组合。
传递性 T：不同尺度的结论可无损互推。三档：T₁ 尺度传递 / T₂ 时间传递 / T₃ 因果传递。
三角命题（框架，C／丙）：有限复杂度下，三者不能同时满格；至多同时满足两个。让出哪一个，就留下哪一类可定位的缺口。
图 0.3　C-A-T 的精确定义。每个性质三档；三个系统分别落在三个顶点上（记忆 C+T、区分 C+A、社会时间 A+T）。注意：这是定义图，不是对真实系统的测量。

背景.4　为什么是这三个性质

读者有理由问：为什么恰好是完备、组合、传递，而不是别的三个？本书的回答分三步，且诚实地标注每步的强度。

  • 经验来源（强）：这三个性质是三本书各自实际保住的两个（加上被让出的一个）——不是事后挑选，而是三个系统各自的选择留下的痕迹。［已知／论证，A—B］
  • 理论呼应（中）：它们分别对应信息论（完备/描述）、代数（可组合）、尺度分析（传递）三个成熟传统，因而有独立的文献支撑。［论证，B］
  • 结构论证（弱）：命题 2.2 说明三角张力来自交互惩罚 ψ；当 ψ ≡ 0 时三角不成立。因此"三"并非逻辑必然，而是三个系统共同的经验事实。［框架，C／丙］
警告 0.1　"三"有人为成分 本书不声称"一切复杂系统都恰好受这三个性质约束"。第 21.6 节会专门自检这一点，并把"是否需要一个不预设三的框架"登记为开放问题 O24。背景章的任务只是说明：这三个性质从三个具体系统里长出来，值得被严肃对待——而不是它们是宇宙的基本常数。

背景.5　本章在全书中的位置

这一页是"从系统到坐标"的桥。第 1 章把三个卡点陈列为症状；第 2 章把坐标形式化（系统四元组、三档定义、可测量坐标、记账不等式）；第 3 章给出检查它的纪律。从第 5 章开始，坐标被带回四个战场，做真正的诊断。

背景章的三句话
  • 先有系统：记忆、区分结构、社会时间是三个被独立研究过的复杂系统。
  • 再有卡点：三者各自把 C、A、T 中的一个逼到极限，账单形状相同。
  • 最后是坐标：C-A-T 是从这些卡点抽象出的诊断坐标，不是先验公理。
