第 5 章　生命系统（一）：记忆、遗忘与容量级联

第一个战场是最容易被误解的：记忆。我们习惯把遗忘当作失败，把记住当作成功。本章要说明的是：遗忘是有限容量下的一张必要账单；而这张账单的形状，正是三角里"让出可组合性"的那一条边。

本章主张 记忆系统不能同时做到：每个时间尺度上都有强的信息论描述（C）、多项记忆能力线性叠加（A）、以及从毫秒到终身的因果链贯通（T）。它保住了 C 与 T，让出了 A。干扰、竞争、边界抑制不是缺陷，而是这张账单的分录。［论证，B／乙；子模性为 A／甲］

5.1　导论：遗忘不是失败

一个不肯丢信息的系统，也丢不掉噪声；一个不肯改变的系统，也无法适应。这句话是第一本书的核心，也是本章的出发点。遗忘之所以必要，有两种看似不同、实则同源的理由。

信息论理由：有限通道容量下，编码必然有损。若表示 Z 的容量小于输入 X 的熵，则 I(X;Z) < H(X)，无法仅凭 Z 完全恢复 X。丢掉的那部分，就是"遗忘"。

学习论理由：拒绝压缩意味着保留噪声，拒绝改变意味着失去适应。一个记忆系统若不能更新，它就会被旧数据锁死。

两种理由指向同一件事：遗忘是压缩的必然伴随物。真正的问题不是"要不要遗忘"，而是"遗忘了什么、以什么代价"。

5.2　信息子模性：能力为什么不能相加

定理 5.1（子模性）［定理，A／甲］ 对任意随机变量 Z, X₁, X₂，
I(Z; X₁, X₂) ≤ I(Z; X₁) + I(Z; X₂)
证明：I(Z;X₁,X₂) = I(Z;X₁) + I(Z;X₂|X₁)，而条件互信息非负，且 I(Z;X₂|X₁) ≤ I(Z;X₂)（条件不增加信息量）。

这条不等式的解释很直白：两条信息中，第二条带来的增益不超过它单独出现时的增益。如果第一条已经"告诉"了 Z 一部分关于第二条的信息，那么第二条的边际收益就被吃掉了。这就是"能力不能线性相加"的精确形式。

放到记忆系统里看：

  • 干扰：两个相似记忆共享表示，第二条的增量小于其单独强度。相似度越高，子模性折扣越大（这也解释了为什么"相似的材料一起背"更难）。
  • 竞争：注意在多个目标间分配时，总的有效信息小于各目标单独占满通道时的信息之和。
  • 边界抑制：当新的记忆侵入已有的编码空间，它吃掉的正是已有记忆的边际。旧记忆并不"损坏"，而是它的相对分辨率被挤低了。
警告 5.1　"扩大容量"不能解决子模性 一个常见的反应是："那把容量做大不就行了？"子模性说的是边际收益递减，不是绝对不足。更大的通道减少的是绝对损失，但"不能线性相加"这个结构性质不变。除非资源无限——而无限资源恰恰意味着复杂度不受约束，三角命题的前提就消失了。

5.3　从毫秒到终身的容量级联

记忆不是一个系统，而是一族运行在不同时间尺度上的系统。第一本书把它们排成一条"容量级联"：

表 5.1　容量级联：时间尺度与主导约束
尺度量级主导约束
感觉登记毫秒—秒即时带宽
工作记忆秒—分钟并列通道数（约 4±1）
短期巩固小时干扰与竞争
长期巩固天—年压缩与重构
终身整合十年—终身自我一致性与叙事
性质：跨学科综述。等级 B／乙；容量数字为公开共识的近似。

这张表的意义在于：它让"传递性 T"显得非常自然——从突触动力学逐级推到终身记忆，是一条连续的因果链。这也正是为什么第一本书能保住 T。代价是：不同尺度上的记忆系统不能简单相加，因为它们在信息论上相互竞争同一批编码资源。这就是被让出的 A。

5.4　先遗后忘：压缩更深的反而保存更久

一个令人费解的现象：老年人常常对几十年前的事记忆清晰，却记不住刚才放下的钥匙。通常的解释是"近期记忆受损、远期记忆完好"。但用容量级联看，这个现象支持另一个解读。

远期记忆往往是压缩更深的记忆。它们已经被巩固、抽象、并入了叙事结构，因而在编码上更"便宜"——占用的边际容量更小。近期记忆还没完成压缩，占用的是昂贵的浅层容量。当总容量收缩（老化、疾病、负荷）时，最先失效的正是那些浅层、未压缩、占用边际高的项目。

观察 5.1　压缩的悖论 在同一容量约束下，压缩更深的表示对容量收缩更鲁棒，但对新信息的可塑性更差。它更抗遗忘（因为它便宜），但更抗更新（因为它已固化）。这正是 C+T 选择的另一面：传递性很强，可组合性很弱。

这个观察有一个现实推论：记忆训练的收益不是均匀的。把时间花在"深压缩"（理解、抽象、与已有结构连接）上，得到的记忆更抗容量收缩；把时间花在"浅编码"（机械重复）上，得到的记忆更容易被干扰吃掉。子模性解释了为什么后者总是"背了就忘"。

5.5　创伤与治疗：两条相反的路径为何都有效

临床上一个反复出现的困惑是：暴露疗法（反复面对创伤线索）与某些以"资源植入/再巩固"为名的疗法，机制看起来相反，却都有效。

用三角的语言，这个困惑是可解的：它们作用在不同的时间尺度上，因而支付的是不同的账单。

  • 暴露疗法作用于较快的学习尺度：通过反复暴露，建立新的、与恐惧不兼容的记忆，覆盖原有反应。它保住了"局部描述完备"（C，明确的恐惧条件反射模型）与"多尺度因果链"（T，从即时生理反应到长期适应），但在"多项能力线性相加"（A）上付账——它常常以泛化减弱或与其他记忆竞争为代价。
  • 再巩固/资源取向的疗法作用于较慢的整合尺度：它改变记忆与自我叙事的关系，保住 C 与 T 的另一个版本，但同样在 A 上付账。

关键不是"哪种更对"，而是：两种路径都在同一个约束下工作，只是选择了不同的时间尺度。把它们对立起来，会让人误以为必须二选一；而容量级联的观点说，它们可能是同一约束在不同尺度上的两种最优解。

5.6　大模型的上下文漂移：同一约束的机器投影

第一本书的另一个贡献，是把人类记忆与 AI 的上下文窗口放在一起看。大语言模型的键值缓存、有限上下文窗口、以及"忘记早期信息"的位置偏差，构成一个机器版的容量级联。

值得强调的是：它不是人类记忆的同构，而是同约束。两者不共享机制，但共享同一组信息论约束——有限通道下的压缩、干扰与遗忘。因此第一处症状（子模性）在机器上也会以机器的方式复现：

  • 长上下文中，越靠前的 token 越容易被"稀释"（相对分辨率下降），这是干扰的子模性形式。
  • 多个任务共享同一模型容量时，总有效能力小于各任务单独微调的能力之和（灾难性遗忘）。
  • 检索增强（RAG）之所以有效，本质上是绕开子模性的一次"外包"：把部分编码任务交给外部存储，减少内部通道的竞争。

5.7　本站诊断：选择 C+T，让出 A

诊断 5.1　记忆系统（C+T，¬A） 保住：每个尺度上的信息论描述（C）；毫秒到终身的因果链（T）。
让出：多项记忆能力的线性叠加（A）。
账单：干扰、竞争、边界抑制；子模性 I(Z;X₁∪X₂) ≤ ΣI。
失效方向：当把多个任务强行塞进同一容量时，总性能低于各任务单独的水平，且下降速度随相似度上升。
反向力量：这条限制使深度压缩、抽象与结构化成为可能——正因为它不能什么都记，才必须把重要的记得更牢、更省、更抗收缩。

必须补上的是这条限制的反向力量：让出 A 不是纯粹的损失。正因为不能线性叠加，系统才被迫学会压缩、抽象与优先级；正因为容量有限，深压缩的记忆才显得珍贵。这不是对限制的美化，而是承认交易的另一面：这条限制使"选择性"成为可能。

5.8　本章小结

记忆系统保住了完备性与传递性，让出了可组合性。子模性是这张账的精确形式：能力不能线性相加。先遗后忘、治疗路径的悖论、大模型的上下文漂移，都是同一约束的不同投影。下一章进入同一战场的另一面：医疗决策的多尺度冲突。
