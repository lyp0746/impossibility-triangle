附录 A　形式化补充：不可能三角的陈述与三个见证

本附录把正文中的形式定义集中起来，供需要核对细节的读者使用。它包含：三档定义、三角命题的精确陈述、三个见证的推导或来源、说明性模型 T 的完整定义与数值结果。

A.1　三档定义

定义 A.1　完备性 C₁ 描述完备：存在有限基元集，使每个子系统的相关现象可由基元组合刻画。
C₂ 计算完备：存在有限算法从初值计算未来的相关状态。
C₃ 预测完备：对感兴趣的量，模型预测落在可接受误差内。
C₁ ⇒ C₂ ⇒ C₃（在相应定义域内）。
定义 A.2　可组合性 A₁ 线性可组合：f(x₁ ∘ x₂) = f(x₁) + f(x₂)。
A₂ 关系可组合：组合不产生新的关系类型。
A₃ 代数可组合：组合在描述空间上封闭且满足明确代数结构。
定义 A.3　传递性 T₁ 尺度传递：λ₁ → λ₂ 的结论可严格推导，误差不随尺度数累积。
T₂ 时间传递：多时间尺度由同一演化方程描述。
T₃ 因果传递：微观因果链可无损累积为宏观结果。

A.2　三角命题的精确陈述

命题 A.1（三角命题，启发式） 设系统 Σ 具有有限描述复杂度 K，运行在多个尺度上。则不存在分配使 (C, A, T) 同时取到各自最强档位。
弱形式（可被 O7 证伪）：(C₁, A₁, T₁) ∉ R(K) 对一切有限 K 成立。
强形式（本书不主张）：存在函数 g，使 C + A + T ≤ g(K)，且 g(K) < 3 对所有有限 K 成立。
状态：弱形式为框架主张（C／丙）；强形式未定义（g 未知）。

A.3　见证 Ⅰ：信息子模性（可证）

定理 A.1（子模性）［A／甲］ 对任意随机变量 Z, X₁, X₂：
I(Z; X₁, X₂) = I(Z; X₁) + I(Z; X₂ | X₁)
由条件互信息非负，I(Z;X₂|X₁) ≥ 0；又因条件不增加信息量，I(Z;X₂|X₁) ≤ I(Z;X₂)。故
I(Z; X₁, X₂) ≤ I(Z; X₁) + I(Z; X₂)
即"能力不能线性相加"。

对应三角：若系统要保住 C（每个尺度有完备的信息论描述）与 T（尺度间因果链），则它在 A（多项能力线性叠加）上付账。第 5 章给出记忆系统的实例。

A.4　见证 Ⅱ：离散—连续缺口（恒等式可证，缺口开放）

定理 A.2（离散分离曲率）［A／甲］ 对有限图 G，取热核 ρ(t) = e−tL/Z(t)，von Neumann 熵 S(t) = −tr(ρ log ρ)。定义
κ_info(G) := −(1/2) S″(0⁺)
则 κ_info(G) = (1/2) Var(λ)，其中 λ 取遍拉普拉斯谱。

缺口：热核展开给出 κ = R/6（R 为标量曲率），而二维 Gauss–Bonnet 定理给出一个与 R/6 相差因子 1/3 的关系。这个 1/3 无法由离散情形代数消去。作者在《区分的演化》中尝试过轨形解释与等变指标解释，两次失败于同一点（带不动点）。缺口当前状态：开放问题 O4。［缺口 B／乙］

对应三角：离散情形保住 C（局部完备）与 A（可加组合），连续极限让出 T（传递性），账单是 1/3。

A.5　见证 Ⅲ：时间错配（命题可证，诊断依赖假设）

命题 A.2（时间错配）［A／甲］ 设 T_min 为动员适应能力所需最短时间，T_available 为可用反应时间。定义
τ = T_min / T_available，　C_ctl = 1 / τ
当 τ ≤ 1，存在适应窗口；当 τ > 1，适应窗口不足，系统必须依赖预先减小暴露或降级。（"τ 增大时诊断置信区间发散"是经验诊断，等级 B／乙。）

对应三角：多尺度社会系统保住 A（干预可组合）与 T（长期追踪），让出 C（对单个情形的精确完备预测）。

A.7　记账不等式（命题 2.2）的证明与推广

命题 A.2（记账不等式，重述） 设系统在预算 K 下支出
cost(c,a,t) = κ_c·c + κ_a·a + κ_t·t + λ·ψ(c,a,t) ≤ K
其中 c,a,t ∈ [0,1] 为三个坐标，κ_· > 0 为单位成本，λ ≥ 0，ψ ≥ 0 为交互惩罚。则
κ_c·c + κ_a·a + κ_t·t ≤ K − λ·ψ(c,a,t) ≤ K

证明。由预算约束直接移项得第一式；由 λ ≥ 0、ψ ≥ 0 得第二式。∎

这个平凡证明的意义在于它指出张力的位置。仅凭预算约束，坐标和只能被上界 K 限制；只有当 ψ > 0（即"同时维持完备与可组合"比"分别维持"更贵）时，坐标和才被压到 K 以下。换句话说，三角不是预算的产物，而是交互惩罚的产物。

推论 A.2.1（无交互则无三角） 若对一切 (c,a,t) 有 ψ ≡ 0，则三个坐标相互独立，可同时接近各自上界。此时三角对其不适用。
推论 A.2.2（归一到 K=2） 取 κ_c=κ_a=κ_t=1、K=2（预算恰好够满两个顶点），则
c + a + t ≤ 2 − λ·ψ < 2　（当 ψ > 0）
这与第 1 版"坐标和恒为 2"的差别在于：上界不是常数 2，而是 K − λψ。当 K 更大时上界更高——模型 T 在 n=12, K=15 下给出 2.16，正是因为其归一化预算大于 2（见 A.6）。
三个交互惩罚来源（ψ 的分解） ψ_desc：完备与可加组合对同一批子系统提出相互制约的刻画要求（第 5 章的子模性是其信息论特例）。
ψ_comp：同时要求"可算的未来（C₂）"与"可跳算的传递（T）"在计算不可约系统上冲突（第 4.5 节）。
ψ_res：同时维持局部完备与跨尺度组合，要求额外的协调时间/注意力（第 7、9 章的时间错配是其表现）。
这条分解把"让出哪个顶点"翻译成"哪一项 ψ 最大"。
警告 A.1　命题 A.2 仍不是普适定理 命题 A.2 是恒等式级别的（移项），但它的解释力取决于 (A1)—(A3) 在具体系统中是否成立、以及 ψ 是否可测。它把"三角为什么不普遍成立"的答案也写清楚了：当 ψ ≡ 0 时不成立。这就是第 21.6 节自检所需要的精确形式。
