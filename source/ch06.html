第 6 章　生命系统（二）：医疗决策的多尺度冲突

第二个战场仍在生命系统里，但对象从"记忆"换成"决策"。医疗系统是三角最容易被观察的地方，因为它把不同时间尺度并置在同一个病人身上。本章的诊断是：医疗制度在多数环节选择了 A+T，因而在"对单个病人的精确完备预测"上付账——而这恰恰是"精准医学"承诺的核心。

本章主张 医疗系统无法同时做到：对每个病人有精确的机制—药理预测（C）、标准化诊疗流程可组合（A）、以及长期疗效可追踪传递（T）。现代医疗制度优先保住了 A 与 T，让出了 C。这不是制度失误，而是一个可以在具体尺度上定位的取舍。［诊断，B／乙］

6.1　导论：同一个病人，不同的时钟

一个糖尿病患者的同一次就诊，可能同时涉及四个完全不同的时间尺度：

  • 分钟级：低血糖的即时处理，错过会致命。
  • 日级：血糖监测与当日用药调整。
  • 年级：并发症（视网膜、肾、神经）的筛查与延缓。
  • 十年级：生活方式、代谢记忆、长期生存质量。

四个尺度要求四种不同的推理。急诊室需要完备、快速、机制清晰的判断（C+T）；慢病管理需要标准化、可复制的流程与长期追踪（A+T）；公共卫生需要群体层面的组合干预（A+T，C 更弱）。把它们塞进同一套制度，就像让一个乐团同时演奏四种拍号。

6.2　急症的分钟级与慢病的年级

把这四个尺度写成一张表，被让出的顶点会立刻显现。

表 6.1　医疗四个尺度的三角选择
尺度典型任务保住让出
分钟级（急症）卒中溶栓、心梗再灌注C+TA（标准化流程难以覆盖个体差异）
日级（住院/门诊）诊断、用药调整C+AT（长期效应难以即时反馈）
年级（慢病）随访、并发症筛查A+TC（无法精确预测个体结局）
十年级（公卫）疫苗、筛查、生活方式A+TC（个体归因困难）
性质：诊断表，等级 B／乙。尺度划分为效率起见，并非临床标准分类。

注意其中最关键的一行：急症选择 C+T，慢病选择 A+T。当同一个病人在两者之间移动（例如从 ICU 转出到社区随访），制度必须在两种三角选择之间切换。而制度通常没有显式地做这个切换——它用的是同一套记录、同一套指标、同一套责任逻辑。于是出现了本章的第一个诊断。

诊断 6.1　尺度切换的空白 多数医疗信息系统与考核制度没有区分不同尺度上的三角选择。结果：急症需要的个体完备性被慢病管理的标准化指标挤压，而慢病需要的长期可组合性又被急症的即时精确性要求打断。冲突不在医学，而在制度对不同尺度的默认。

6.3　新药开发的“第二道墙”

制药业有一个被反复讨论的数字：从临床前研究到最终获批，总通过率约在千分之三量级（不同适应症差异很大，此数为量级，非精确值，B 级）。更值得注意的是失败发生在哪里：第二期临床试验（有效性）是最大的坟场。

标准解释是"物种差异""遗传背景异质"。三角语言给出一个补充解释：每一道开发环节选择了一个不同的三角顶点，而这些顶点之间的传递性极差。

表 6.2　药物开发各阶段的三角选择
阶段选择代价
体外 / 靶点C + AT 失效：无法传递到活体动力学
动物模型C + TA 失效：个体差异大，难标准化
一期（安全）A + TC 失效：无法预测个体毒性
二期（有效性）A + TC 失效：无法预测谁获益
三期（确认）A + TC 失效；T 也脆弱（长期效应）
性质：阶段诊断，等级 B／乙。通过率为公开统计的量级。

从 C+A 到 A+T 的两次转变，正是传递性被两次让出的位置。"第二道墙"就是 T 失效墙。它不是科学不成熟，而是不同尺度的模型必须换三角选择——而换选择的那一刻，前一个尺度的结论就不能再无损传递。

6.4　循证医学的强 A 与它看不见的东西

循证医学（EBM）是过去半个世纪医学最成功的方法论。它的核心是随机对照试验与系统综述：把"证据"标准化、可复制、可比较。用三角语言，EBM 是一个强 A（可组合：不同研究的效应量可以合并）与强 T（可传递：从试验到指南到实践）的选择。

被让出的正是 C：对单个病人的精确、完备预测。一个平均效应量告诉你"在试验人群里，平均而言，风险下降了多少"，它不告诉你"这位病人会不会获益"。这不是 EBM 的缺陷，而是它选择 A+T 后必然的账单。

警告 6.1　平均数不是个体预测 把"平均效应显著"读成"对这个病人有效"，是把 A+T 的结论误当作 C 的结论。这正是三角诊断能防止的一类错误：结论的强度不能超过它所依赖的三角选择。循证医学在最能标准化的地方最强，在最需要个体预测的地方最弱——两者不是矛盾，而是同一个选择的两面。

6.5　个性化医学的承诺为何难以兑现

"精准/个性化医学"的愿景是：通过基因组、分子标志物与大数据，为每个病人给出精确预测。这在三角语言里，是在要求同时保住 C（个体完备）与 A（可组合的标志物组合），因而必然在 T 上或 C 的档位上付账。

现实中的折中是"分层医学"：先用简单的临床特征把人群分层（强 A），再在每一层内允许个体化调整（弱 C），最后靠长期随访补 T。它不是精准医学的完整实现，而是三角约束下的一个可行点。把"分层"误读成"精准"，是政策话语里最常见的过度承诺。

6.6　本站诊断：让出 C 或让出 A

诊断 6.2　医疗系统（分尺度） 急症：C+T，让出 A —— 个体化程度高，标准化流程难覆盖。
慢病/公卫：A+T，让出 C —— 流程可复制、长期可追踪，但无法预测个体结局。
开发/监管：阶段性地在 C+A 与 A+T 间切换，切换处产生 T 失效墙。
反向力量：让出 C 使大规模、可复制、可问责的医疗成为可能——正因为它不追求个案完备，几十亿人才能获得一致的底线医疗。

与上一章一样，必须写出反向力量：让出 C 不是纯粹的损失。正因为医疗制度放弃了"对每个个体精确完备预测"的执念，它才能建立可大规模复制、可比较、可问责的诊疗体系。这条限制使"可及的底线医疗"成为可能。个性化医学要追求的，不是推倒这个体系，而是在它之上增加一层受控的个体化。

6.7　本章小结

医疗系统在不同尺度上做不同的三角选择：急症选 C+T，慢病与公卫选 A+T，药物开发在两个选择之间切换并因此撞上 T 失效墙。循证医学的强项与弱项，都是同一选择的两面。下一章离开生命系统，进入物理系统：气候与能源的时间错配。
