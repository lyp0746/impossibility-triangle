第19章　书写方式：如何诚实标注选择

一位作者在书里写“本书在 C 上让出了很多”，编辑建议删掉，说读者不爱看。他留下了。不标出自己让出了什么，读者就会以为那是免费的。

本书本身也是一件"被让出的顶点"的产品。这一章把作者在本书与前三本书中使用的书写纪律提炼出来，供任何需要做类似选择的人参考。核心是：把选择与代价写在明处，让读者知道在哪里可以安全地相信。

本章主张 诚实的书写不是表演谦逊，而是把假设、分级与失效边界显式化。它要避免两类对称的失败：过度宣称（用弱证据说强话）与过度谦卑（什么都不敢说）。［框架，B／乙］

19.1　导论：选择是交易，不是判决

第 3 章说过：一份诊断性著作最危险的地方，是它的结论听起来永远对。书写方式要解决的正是这个问题。把"我选择了什么、付了什么账、边界在哪里"写清楚，是让读者能够反驳你的前提。

19.2　显式的假设陈述

假设不该藏在"模型局限"一节的角落里。它应该在方法论开场就被声明。

原则 19.1　假设前置 在正文开头就写清："本书选择保住 C 与 T，因此让出 A。这意味着：我不声称多项能力可以线性叠加，也不声称我的结论可以拆成独立可优化的目标。"
好处：读者从一开始就知道该用什么标准检验你；异议可以在前提层面提出，而不必等到结论处才觉得"哪里不对"。

19.3　分层的论证标注

不要把所有论述混成一锅。按严格度分层：

  • 第一类：完全严格、可机器验证的结果（定理、可复算的恒等式）。
  • 第二类：框架性主张，基于类比与观察（诊断、模式）。
  • 第三类：开放问题、待检验的方向（猜想、纲领）。

三类的排版、语气与等级都应不同。把第三类写得像第一类，是最常见的学术不诚实；把第一类写得像第三类（过度谦卑），则会浪费读者的信任。

19.4　显式的失效边界

"需要进一步研究"是无效的边界声明。好的边界声明是可操作的：

表 19.1　无效与有效的边界声明
无效有效
"模型有局限。""当 τ > 3 时，置信区间扩大到预测的一个数量级。"
"还需要更多研究。""在维数 n > 3 时，传递性显著失效。"
"结果可能不适用于所有情况。""此结论仅对有限图成立；连续情形留给第 20 章的开放问题。"

19.5　反例进正文，地图只定性

两条与作者系列一致的纪律。

纪律 19.1　反例进正文 不要只报告支持结论的案例。一个被放在正文里的反例，比十个支持案例更能建立信任。本书的类型：第 6 章药物开发的失败墙、第 12 章学科分裂的代价、附录 增补：上游、边界与对话 一次被证伪的强主张。
纪律 19.2　地图只定性 当框架被用来"覆盖"某个领域时，只做定性定位，不做定量预言。地图不是领土；把地图当领土，是过度宣称的一种形式。

19.6　两类对称的失败：过度宣称与过度谦卑

警告 19.1　两类失败是对称的 过度宣称：用 C 级的证据说 U4 级的话——"这揭示了 A 与 B 的深刻统一"，而实际只给出了"两者都满足某个不等式"。
过度谦卑：把每个主张都弱化成"或许在某种意义上暗示了一种可能的联系"——什么都没说，却显得谨慎。
共同点：两者都逃避了"可被反驳"的责任。前者用宏大掩盖空洞，后者用谨慎掩盖空洞。严肃的书写必须在中间：命题足够强以便被攻击，边界足够清楚以免欺骗。
人的尺度

一位作者在书里写：“本书在 C 上让出了很多。”编辑建议删掉，说“读者不爱看”。他坚持留下，因为他知道：不标出自己让出了什么，读者就会以为那是免费的。

19.7　本章小结

诚实的书写 = 假设前置 + 分层标注 + 可操作的边界 + 反例进正文 + 拒绝两类对称失败。这套纪律既适用于学术著作，也适用于制度文件、研究报告与政策白皮书。下一章把全书收成一个可带走的工具：决策者的诊断手册。
