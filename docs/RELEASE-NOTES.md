# 修订说明

本文件说明本次发布的构成。全书正文与元数据不含版本号；下方按材料类型说明，供读者了解内容边界。

## 内容构成

- **正文**：五部分、二十三国。第一部分（问题的现身：三处症状、不可能三角的形式化、分级纪律、与不可能定理/计算/系统论对话）、第二部分（现实诊断：生命、物理、社会、人工四个战场，每章含定量诊断与历史脉络）、第三部分（形成、演化与更新：三阶段成长、学科分裂、学术体制、范式转变、制度性管理）、第四部分（设计智慧：分层有效性、有限理性、制度权衡、优雅降级、书写方式、诊断手册）、第五部分（边界与纲领：证据现状、预测力分级 L1—L4、三角之外、结语）。
- **前置**：先读这一页（三条可检验的诊断）、前言、十分钟读懂本书、阅读合约、读者指南（含案例选择标准）、术语与分级速查。
- **后置**：结语、附录 A—Q。
- **图表**：4 幅 SVG 插图。图 0.1 由 `analysis/triangle_frontier.py` 精确枚举生成，其余由 `analysis/make_figures.py` 确定性生成。
- **形式化（第 2 章、附录 A）**：系统四元组 Σ=(E,R,ℒ,K)、复杂度三分量 (K_desc, K_comp, K_res)、三档定义、可测量坐标 (c,a,t)、三角命题 2.1（准形式，猜想）、记账不等式命题 2.2（条件命题，含 A.7 证明与 ψ 分解）。
- **定量诊断**：第二部分每章配有“定量诊断”与“历史脉络”节；全部关键数字集中登记于附录 K 与 `data/cases.csv`。
- **上游对话（第 4 章、附录 N）**：计算不可约性、P vs NP、算法信息论、系统论三次尝试、涌现谱系。
- **研究纲领（附录 L、第 22 章）**：O1—O25 按 P0—P3 分级的议题库。
- **可证伪登记（附录 E、J）**：登记 P1—P9；并照实记录两次被证伪/削弱的强主张（F1、F2）。
- **系列对应（附录 M）**：与前三本书的术语、证据等级、三角定位逐项对应。
- **延伸（附录 O、P、Q）**：意识/AI/人机协作三个前沿；法律/公卫/能源/软件四个延伸战场；知识演化的定量指标与历史年表。
- **可操作性（附录 H.4—H.5）**：研究生培养制度的完整五步诊断案例。
- **反面检验（第 5—10 章、附录 P.6）**：每个战场诊断“会怎样被推翻”的具体情形。
- **案例（第 11.7、15.7）**：机器学习的三阶段；一个研究机构的更新协议。
- **形式化兑底（附录 A.8—A.11）**：关系集的三种表示、复杂度分量换算、前沿随规模的数值实验、数据等级细化（B1—B3 / C1—C3）。
- **时间维度**：`data/cases_timeseries.csv`（近似锚点，用前须回溯原始来源）。
- **历史脉络（第 8.7、9.7.1、10.7）**：教育、民主、组织的三角演化与驱动力。
- **反面检验可操作性评级**：第 5—10 章与附录 P.6 标明哪些反检可自行测试。
- **附录 S**：演化视角的三角（生物/文化/技术）及可反驳推论。
