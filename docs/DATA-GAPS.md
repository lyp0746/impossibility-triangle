# 证据与数据缺口清单

本清单汇总《选择的代价》中无法获得、无法证明或无法验证的内容。一个缺口被写出来，就是一个结果。

## 一、理论缺口

| 缺口 | 需要什么才能填上 | 难度 | 当前替代 |
|---|---|---|---|
| 复杂度 K 的统一度量 | 使三档性质的损失与 K 可比 | 高 | 仅定性（第 2、21 章） |
| 可达域 R(K) 的形状 | 证明或数值刻画其几何 | 中—高 | 说明性模型前沿（附录 A） |
| 三角命题的证明/反例 | 一般性定理或 O7 反例 | 很高 | 三个见证（第 5、7、12 章） |
| 三档之间的换算率 | 跨领域 C₁↔C₂↔C₃ 换算 | 高 | 无 |
| 1/3 缺口的解释 | 新数学构造 | 高 | 三种出路并列（第 12.5 节） |
| 第四性质的存在性 | 独立可测且不冗余的性质 | 高 | 登记为纲领（第 22 章） |
