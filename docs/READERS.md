李毅芃　著　·　CC BY 4.0

## 这本书是什么

一份跨学科理论专著与诊断手册。它把作者此前三本书中三处"无法弥合的矛盾"——记忆的遗忘与更新、数学的离散完备与连续传递、社会系统的时间错配——诊断为同一个结构性困境：**任何有限复杂度的知识系统都不能同时完整地拥有局部完备性（C）、可组合性（A）与跨尺度传递性（T）；至多两个。**

## 这本书不是什么

- 不是"一切系统都受三角约束"的定理。通用证明尚未给出，三角是组织坐标。
- 不是对记忆、气候、教育、医疗、治理领域的完整理论。多数诊断只到"可写出 C-A-T 选择"（B 级）。
- 不是已通过同行评审的定稿。它是一份标注了全部边界的预印本。

## 如何阅读

1. **怀疑论者**：先读「先读这一页」→ 第 5 章 → 第 12.5 节 → 第 21 章 → 附录 E、J。
2. **关心现实诊断**：第 2 章 → 第二部分（第 5—10 章）。
3. **关心最初的问题**：第三部分（第 11—15 章）。
4. **要把框架用起来**：第 20 章 → 附录 G。

## 分级制度

全书使用两条独立的分级轴：

- **证据等级**：A（可独立复现/可证）／B（公开来源，部分约束）／C（方向性）。
- **概念等级**：甲（定义清晰）／乙（依赖未证前提）／丙（形成中）。

结论强度 ≤ 证据强度。一个 C 级命题永不被写成定理。
