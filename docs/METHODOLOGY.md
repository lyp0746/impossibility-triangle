# 方法论说明

本文件说明《选择的代价》所使用的研究方法，供读者评估其可信度。

## 一、证据分级

三级证据标准贯穿全书：

- **A 级**：可独立复现、可由机器验证或可证明的结论（如信息子模性、离散曲率恒等式、说明性模型的枚举前沿）。
- **B 级**：有公开来源、部分约束、方向可靠的结论（如四个战场的诊断、三阶段成长模式）。
- **C 级**：概念推理、探索性假设、初步猜想（如三角命题本身、第四性质的存在）。

结论强度不超过证据强度：一个 C 级命题永远不会被写成定理。

## 二、概念分级

- **甲**：定义清晰、无歧义。
- **乙**：定义基本清晰，但依赖至少一个未证前提。
- **丙**：概念仍在形成中。

## 三、断言标记

［已知］／［论证］／［假说］／［待验证］四类，与证据等级正交。

## 四、三层结构

- **硬核层**：信息子模性、离散分离曲率恒等式、说明性模型 T。可复算或可证明。
- **诊断框架层**：三角命题、四个战场的诊断、三阶段成长模式。依赖硬核，但外推时引入未证前提。
- **可选工具层**：诊断手册、制度模板、降级清单。不承载真值，只承载有用性。

读者可以只接受其中一层。

## 五、可证伪登记

`docs/preregistration/registry.json` 与 `checkups.csv` 构成一个 append-only 账本。规则：

1. 事前登记；2. 以方向判定；3. 分别报告预测与观察；4. 只追加，永不改写。

`analysis/preregistration_checkup.py` 校验账本结构、日期顺序与命题编号。

## 六、自我检视与失败记录

本书不隐藏失败。第 21.6 节正面处理"三角是否只是分类的假象"；附录 J 记录两次被作者自己的脚本推翻的强主张（F1、F2）。**如果这两条失败记录反而让你更相信框架，那就说明：框架的可信度来自它愿意公开自己在哪里碎过。**

## 七、稳健性与复现

```bash
python analysis/triangle_frontier.py   # 模型 T 的精确枚举
python analysis/make_figures.py        # 正文插图
python analysis/audit.py               # 校对（编号/交叉引用/文献一致性）
```

所有数值由公开定义直接计算，可独立复现；任何自称"示意性的"数字均在正文或附录中标明。
