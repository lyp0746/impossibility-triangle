# 欢迎补充数据与批评

本纲领的核心是"可被反驳"。它欢迎三类贡献：**数值复现、缺口填补、命题反驳**。

## 一、数值复现

说明性模型 T 与正文插图都可以独立复现：

```bash
python analysis/triangle_frontier.py   # 复现模型 T 的可达前沿（n=12, K=15）
python analysis/make_figures.py        # 复现正文插图
python analysis/audit.py               # 复现校对清单
```

若你得到与书中不一致的数字，请报告——那说明本书有误。

## 二、缺口填补

本清单中最优先的可执行任务是 **O7**：构造（或证明不存在）一个同时把完备性 C、可组合性 A、传递性 T 推到满格的有限复杂度系统。这是三角命题的生死线，也是唯一能一次性推翻全书的路径。若你完成它，请按附录 E 的流程登记。

## 三、命题反驳

下列命题是最容易攻击的（均标注 C 或 B 级）：

- **F1**：三角的坐标和存在普适上界 2（**已被作者自己证伪**，见附录 J）。
- **F2**：每个多尺度系统恰好让出一个顶点（**已被削弱**，见附录 J）。
- **P9**：不存在同时满格 C、A、T 的有限系统（开放）。
- **P4/P5/P7**：记忆干扰、医疗尺度切换、C+T 飞地的经验方向。
- **第 21.6 节**：三角是否只是分类的假象。

## 四、如何提交

1. 在 GitHub 仓库开 issue 或 PR。
2. 若涉及预测，请在 `docs/preregistration/checkups.csv` **追加**一行（绝不修改旧行）。
3. 遵守两条纪律：**只追加**、**分别报告预测与观察**。
