# 数据与来源说明

本文件登记《选择的代价》中引用数据的来源、等级与获取方式。

| 结果 | 来源 | 等级 | 复现命令 |

| 信息子模性 | 香农信息论（条件互信息非负） | A | 解析证明 |

## 三、无法获取的数据

## 四、使用原则

1. **量级优先**：凡口径不一的数据，只取量级，不取点值。
2. **等级随行**：所有数字在正文中带等级标注。
3. **C 级不转引**：C 级数字仅用于展示结构，不得转引为经验事实。
4. **来源公开**：所有引用均可在附录 C 或各章参考文献中查到。
